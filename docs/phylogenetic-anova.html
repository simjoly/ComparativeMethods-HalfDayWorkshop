Half-day Workshop on Phylogenetic Comparative Methods

8 Phylogenetic ANOVA

So far, we have only analysed continuous quantitative characters. But it is also possible to analyse categorical characters with PGLS abd perform an ANOVA or an ANCOVA.

8.1 Do carnivores have larger home ranges than ungulates?

This is one of the classic examples of the comparative method (Garland et al. 1993). The dataset contains body mass (kg) and home range area (km2) for 49 mammal species: 19 Carnivora and 30 ungulates. It is the dataset of Garland et al. (1992), and it is also distributed in the R package phytools (data(mammal.data) and data(mammal.tree)).

mammal_homerange.csv

mammal_homerange.tre

Let’s prepare the data for analysis.

# load required libraries
library(nlme)
library(ape)

# Load data
mammals <- read.csv("./data/mammal_homerange.csv")
mammaltree <- read.tree("./data/mammal_homerange.tre")

# Transform clade to factor for analysis
mammals$clade <- factor(mammals$clade)

# Compute log10 values for analysis
mammals$logMass <- log10(mammals$bodyMass_kg)
mammals$logHR <- log10(mammals$homeRange_km2)

# Add rownames and order table following the tip labels of the tree
rownames(mammals) <- mammals$species
mammals <- mammals[mammaltree$tip.label, ]

The question is simple: for a given body size, do carnivores, which eat prey at low densities, need larger home ranges than herbivores?

cols <- c("#7570b3","#d95f02")
plot(logHR ~ logMass, data = mammals, pch = 21, bg = cols[mammals$clade],
     xlab = "log10 body mass (kg)", ylab = "log10 home range (km2)")
legend("topleft", legend = levels(mammals$clade), pt.bg = cols, pch = 21, bty = "n")

Before going further: how would you analyse these data? What would you conclude?

A standard analysis of covariance (ANCOVA) provides the answer:

hr.ols <- gls(logHR ~ logMass + clade, data = mammals)
round(summary(hr.ols)$tTable, 4)
##                  Value Std.Error t-value p-value
## (Intercept)    -0.1055    0.2466 -0.4278  0.6708
## logMass         0.9970    0.1448  6.8851  0.0000
## cladeUngulates -1.0224    0.2088 -4.8959  0.0000

The model tells us that body mass is significantly (p-value = 0) positively correlated to home ranges with a slope of 1, as expected. The model also shows that ungulates have home ranges about 10 times smaller (-1.02 on the log10 scale) than carnivores of the same size, and the difference is highly significant (p-value = 0).

However, we’ve been ignoring the phylogeny so far. Now let’s look at where the species are on the phylogeny.

op <- par(mar = c(1,1,1,1))
plot(mammaltree, cex = 0.6, label.offset = 2)
tiplabels(pch = 21, bg = cols[mammals$clade], cex = 1.2)

par(op)

You can see that the carnivores and the ungulates form distinct clades. Whatever made carnivores and ungulates different, it could have happened only once on the branches separating the two clades. From an evolutionary point of view, there is only one comparison here, even if there are 49 species.

Let’s fit the same model while accounting for the phylogeny.

hr.lambda <- gls(logHR ~ logMass + clade, data = mammals,
                 correlation = corPagel(0.5, phy = mammaltree, form = ~species))
summary(hr.lambda)

Under Pagel model, the clade difference is greater than with the ordinary least squares, but the results is less significant (p-value = 0.022). The lambda estimate (\(\lambda\) = 0.8163428) suggests that the residuales are quite strongly phylogenetically correlated. Its standard error is about three times larger than in the OLS model, because the model knows that the 49 species are not 49 independent observations of the effect of diet. This analysis supports the idea that ungulates have lower home ranges than carnivores, but that there is not a strong support for this conclusion.

There is a second, less obvious problem. Look at the allometric slope when the clade is not included in the model:

round(summary(gls(logHR ~ logMass, data = mammals))$tTable, 4)
##              Value Std.Error t-value p-value
## (Intercept) 0.0109    0.2994  0.0363  0.9712
## logMass     0.6071    0.1476  4.1141  0.0002
round(summary(gls(logHR ~ logMass, data = mammals,
          correlation = corPagel(0.5, phy = mammaltree, form = ~species)))$tTable, 4)
##               Value Std.Error t-value p-value
## (Intercept) -1.3387    0.5304 -2.5240   0.015
## logMass      1.2252    0.1736  7.0581   0.000

The OLS slope is about half the PGLS slope. Carnivores are, on average, smaller than ungulates but have larger home ranges. When the two clades are pooled, this single deep difference flattens the slope. However, incorporating the phylogenty largely corrects for this even if the clade in not in the model because it provides the phylogenetic structure of the data.

Take-home messages: (1) a significant result with many species can rest on a single evolutionary event; (2) the phylogeny affects not only \(p\)-values but also parameter estimates; (3) even with PGLS, a difference between two clades remains a comparison with one evolutionary replicate (see chapter 11).
